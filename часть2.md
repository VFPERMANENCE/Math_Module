# Практическая работа №2. Часть 2 — Мутационное тестирование

## 📁 Состав проекта
* `src/main/Main.java` — класс с примерами вызовов.
* `src/main/MathModule.java` — модуль со статическими математическими методами.
* `src/test/MathModuleTest.java` — набор модульных тестов на JUnit 5.


### 1. Исправление ошибки в `MathModule.java`
* В методе `isEven` исправлена логическая ошибка проверки на чётность:
    * **Было:** `return n % 2 == 1;`
    * **Стало:** `return n % 2 == 0;`

### 2. Доработка тестов в `MathModuleTest.java`
* Добавлен новый модульный тест `testIsEven()` для проверки работы исправленного метода `isEven`:
  ```java
  @Test
  void testIsEven() { assertTrue(MathModule.isEven(2)); assertFalse(MathModule.isEven(3)); }
