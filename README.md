# MathModule — модуль математических функций

## Описание
Модуль `MathModule` содержит 5 статических методов для простых математических операций.

## Функции
- `add(int a, int b)` — сумма a и b.
- `subtract(int a, int b)` — разность a и b.
- `multiply(int a, int b)` — произведение a и b.
- `divide(int a, int b)` — деление a на b. При b == 0 выбрасывает IllegalArgumentException.
- `isEven(int n)` — true, если n чётное, иначе false.

## Запуск
mvn test

## Примечание
В модуле преднамеренно оставлена одна ошибка (для обмена с другим участником).
